# Football Tactics Board（足球战术板）

把"画在黑板上的战术"数字化：拖拽排兵布阵、保存多套方案、一键导出分享给队员的赛前战术准备工具。浏览器直接打开即用，无需注册登录。

**在线使用**：https://chenlingfan92-star.github.io/football-tactics-board/

## 适用场景

- 赛前：制定首发 11 人、阵型和战术，导出图片发到球队群
- 赛中：根据比分和局面实时调整换人方案
- 训练：用战术板讲解站位、跑动和职责

## 功能特性

- **球员与球队管理**：花名册录入任意数量球员（姓名/球衣号码/位置），场上恒为 11 人（含门将），替补席不限人数，拖拽换人
- **战术板画布**：标准足球场俯视图，场上任意拖拽站位，替补席 ↔ 场上拖拽换人
- **阵型**：内置 4-4-2、4-3-3、3-5-2、4-2-3-1 等预设一键摆阵；支持保存自定义阵型
- **双方对位模式**：同一块球场叠加双方 22 人对比阵型与攻防对位，对方镜像摆位
- **战术库**：内置进攻/防守/定位球 11 套模板；自由绘制传球箭头（实线黄）、跑位箭头（虚线白）、高亮区域与文字标注，可存为自定义战术
- **战术演示**：关键帧编排"摆一步、录一步"，播放/暂停/倍速调节；内置角球、任意球、高位逼抢演示模板；导出 GIF 动图、MP4/WebM 视频、分帧 PNG
- **导出分享**：整块战术板导出 PNG；方案导入/导出 JSON（跨设备迁移）
- **竖屏球场模式**：适合手机竖屏查看与讲解；各功能区可收起/展开
- **移动端适配**：响应式布局，触屏拖拽
- **撤销/重做**：按钮 + Ctrl+Z / Ctrl+Y

## 本地运行

```bash
npm install      # 安装依赖
npm run dev      # 开发模式（浏览器打开）
npm run build    # 构建产物到 dist/（纯静态，可部署到任意静态托管）
npm run preview  # 本地预览构建产物
```

## 数据存储

方案、球队与演示数据保存在浏览器本地（LocalStorage/IndexedDB），无需登录、离线可用。换浏览器或换设备时，可通过「导入/导出 JSON」迁移方案。

## 技术栈

- React 19 + TypeScript + Vite（界面与工程）
- Zustand（状态管理）
- SVG（球场、球员、箭头等高保真矢量渲染，便于交互与导出）
- html-to-image（PNG 导出）、gifenc（GIF 编码）、MediaRecorder（MP4/WebM 导出）

## 项目结构

```
src/
├── components/   # 球场、球员、替补席、工具栏、演示面板等界面组件
├── store/        # Zustand 状态（战术板/演示/拖拽/编辑/工具栏/界面）
├── formations.ts # 预设阵型
├── tactics.ts    # 战术模板
├── demos.ts      # 演示模板
├── drag.ts       # 拖拽交互
├── draw.ts       # 箭头/区域/文字绘制
└── export.ts     # PNG/GIF/视频/JSON 导出
```
